
# 2 - Conceitos básicos

## O que é o sistema gerenciador de banco de dados (SGBD)?

Software para o gerenciamento de banco de dados. Exemplos: PostgreSQL, MySQL, etc.

## Qual a diferença entre DDL e DML?

- **Data Definition Language (DDL):** define e estrutura o banco de dados (tabelas, colunas, índices) usando comandos como `CREATE`, `ALTER`, `DROP`.
- **Data Manipulation Language (DML):** manipula os dados contidos nessa estrutura, como inserir, atualizar ou remover registros, usando `INSERT`, `UPDATE`, `DELETE`.

## Qualidades do PostgreSQL

Ele é baseado em um modelo objeto-relacional, mantendo assim as tabelas relacionais, mas adiciona recursos inspirados na programação orientada a objetos.

Características adicionais:
- Tipos de dados personalizados (CREATE TYPE).
- Herança de tabelas.
- Funções e operadores definidos pelo usuário.
