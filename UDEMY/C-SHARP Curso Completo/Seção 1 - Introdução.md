
# Diferença entre .NET e Csharp

- **C#:**  linguagem de programação da Microsoft utilizada para você escrever do seu programa.
- **.NET:** plataforma e ambiente de execução da Microsoft que fornece o ambiente de execução, bibliotecas, ferramentas e o compilador.

# Como funciona o processo de compilação?

O código C# é compilado para **Common Intermediate Language (CIL ou IL)**  pelo compilador **Roslyn**. Em seguida, esse código CIL será compilado para linguagem de máquina pelo **Just-In-Time (JIT)**, presente dentro do ambiente de execução **Common Language Runtime (CLR)**. Dentre outras funcionalidades do CLR estão garbage collector ou gerenciamento de memória e também tratamento de exceções.

# Nota minha

## Diferença entre .NET Framework e .NET Core?

O **.NET Framework** é a versão original (exclusiva para Windows) e mais antiga e o **.NET Core** é a versão multiplataforma (roda em Windows, Mac e Linux) e de código aberto.
