
## 3. Controle de versão com Git & Conceitos importantes

### O que é controle de versão?

Uma técnica que possibilita gerenciar as diversas versões de um projeto. Por exemplo, é possível retornar para versões anteriores do projeto, mesclar duas ou mais features novas criadas por equipes diferentes do projeto, entre outras. **O Git é uma ferramenta que auxilia no controle de versão.**

### O que é o GitHub?

É uma aplicação web que utiliza o Git para o controle de versão, porém ele fornece uma interface visual assim como um armazenamento em nuvem para projetos.

### O que é um repositório (ou repo)

Um local onde fica armazenado o projeto.
